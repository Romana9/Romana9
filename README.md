# Khaled Romana

**Flutter Developer** · Mansoura, Egypt

I build and ship mobile apps for a living — 2.5+ years of production Flutter work, with 20+ applications live on the App Store and Google Play. Most of that work has been in e-commerce, classifieds and auction marketplaces, food delivery, on-demand booking, automotive, and multi-role service platforms: apps with real users, real payments, and real backends that don't always behave. I care about clean architecture that survives handoffs, and about the last 10% of a release — store review cycles, payment edge cases, push notification deep links — that decides whether an app actually works in the field.
